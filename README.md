# GREENROOT — AgriTech Concept Website

Responsive single-page concept site for a premium international agriculture + AgriTech brand.

## Files
- `index.html` — complete website
- `styles.css` — responsive visual system, light/dark themes, animation
- `app.js` — filtering, mobile navigation, theme preference, scroll reveals, illustrative animated metrics, gallery lightbox, FAQ and demo form
- `assets/favicon.svg` — brand favicon

## Run
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Internet
Google Fonts and Unsplash photography are loaded remotely, so an internet connection is needed for those assets. The abstract hero artwork is CSS/inline SVG.

## Concept disclosure
GREENROOT is a fictional portfolio concept. Products, services, research directions and featured projects are illustrative, not real commercial offers or completed client work. Impact counters are design statements, not measured results. The contact form validates in the browser and displays a confirmation; it does not transmit or store submissions.
